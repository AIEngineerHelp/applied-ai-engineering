How a knowledge graph answers what chunk search misses

Six short documents become a graph of entities and relations. Then both methods race to answer the same questions.

Scripted and computed. Scripted: the six documents, the extraction results (hand-written JSON in the format an LLM extractor returns), each question's graph query and its correct answer. Computed in your browser: entity resolution, the graph, every traversal, the TF-IDF chunk ranking and every verdict. TF-IDF stands in for an embedding model so the comparison is offline and repeatable. Read the article.
