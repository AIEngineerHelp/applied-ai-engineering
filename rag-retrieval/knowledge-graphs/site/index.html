        What is scripted and what is computed. Scripted: the documents, the extraction results (hand-written JSON in the format an LLM extractor returns), each question's graph query and its correct answer. Computed in your browser: the highlights, entity resolution, the graph, the traversal, the TF-IDF chunk ranking, and every verdict. TF-IDF stands in for an embedding model so the comparison is offline and repeatable.
