Storage & embeddings

Local JSONL passages, a SciPy BM25 matrix, and memory-mapped Gemini embedding vectors. No separate database service is required.

Citation enforcement

The model returns structured claims and passage IDs. The server validates every ID against the exact selected context before displaying an answer.

Honest evaluation

Recall, MRR, and nDCG use dataset labels. Correctness, groundedness, and context relevance use a fixed judge rubric. Unrun scores remain pending.
