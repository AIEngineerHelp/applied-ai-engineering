    How this is calculated

    Token counts are estimates (about 4 characters per token); real tokenizers differ. The shared prefix is written to the cache once, then read by every later request, as long as requests arrive closer together than the cache lifetime. The per-conversation prefix is written on each conversation's first turn and read on the others. Everything else is billed at the normal input price. Prefixes shorter than the model's minimum aren't cached. Output tokens cost the same either way, so they're left out.
