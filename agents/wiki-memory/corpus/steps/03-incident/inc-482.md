# INC-482: nightly exports failed

Severity 2, 4 to 6 April 2026. Lead: [[amara-osei]] ([[src-inc-482]]).

- Cause: the [[billing-api]] limit dropped from 100 to 50 requests per second on 3 April; [[ledger-export]] still sent 80.
- Impact: about 210 export requests delayed by up to three days.
- Fix: the job sends 40 requests per second and backs off on HTTP 429.
- Prevention: see [[api-rate-limits]].
