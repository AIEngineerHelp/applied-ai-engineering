# Literature review (PubMed)

You are searching the biomedical literature. Aim for the strongest evidence first.

## Build the query
- Combine the drug or drug class with the condition or outcome: `semaglutide AND pancreatitis`.
- Prefer synonyms joined with OR in parentheses: `(GLP-1 receptor agonist OR semaglutide OR liraglutide)`.
- To find the strongest designs, add a filter: `AND (meta-analysis[pt] OR systematic review[pt] OR randomized controlled trial[pt])`.
- If a search returns nothing, broaden one term at a time. Never search more than four times.

## Read each abstract for
- **Population**: who, how many, which condition.
- **Intervention and comparison**: drug, dose, versus placebo or active control.
- **Outcome and effect**: the number that matters (hazard ratio, risk ratio, mean difference) with its confidence interval.
- **Design**: meta-analysis > randomised trial > cohort > case series > case report.

## Write the finding
- One claim per result, in plain words, with the number, in this form: "In a meta-analysis of N trials (n=…), <drug> <did / did not> change <outcome> (RR …, 95% CI …–…)." Fill it only from the abstract.
- Cite every claim with the PMID it came from.
- Say what you could not find. An honest gap beats a guess.
