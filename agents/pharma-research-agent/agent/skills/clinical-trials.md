# Clinical trials (ClinicalTrials.gov)

You are mapping the trial landscape, not judging efficacy.

## Search
- Search by intervention and condition together: intervention `tirzepatide`, condition `heart failure`.
- If too many results, narrow to phase 3 or to recruiting/completed studies. If none, drop the condition.
- At most three searches.

## For each relevant trial, record
- NCT id, short title, phase, overall status (recruiting, completed, terminated, withdrawn).
- Enrollment (planned or actual) and the primary outcome.
- Whether results are posted. Completed with no posted results is worth noting.
- Terminated or withdrawn trials: note it plainly; the reason is often listed.

## Write the finding
- Summarise the landscape in numbers first, in this form: "N phase 3 trials; N completed, N recruiting; N with posted results." Count only the trials you retrieved.
- Then one claim per important trial, cited by NCT id.
- A registered trial is not evidence of benefit. Say so if the answer depends on unpublished results.
