## Projects and resources

[Dino Runner × Jev](dino-runner-jev/README.md) ([live demo](https://dino-runner-jev.vercel.app)) is an original endless-runner game in the style of Chrome's offline dinosaur. You, a rule bot, or TypeSafe's Jev can play it. Code handles physics and timing; Jev chooses jump, duck, or run for each obstacle. Paused and real-time modes separate decision quality from latency. The cartoon-style page shows each decision above its obstacle and a telemetry panel with per-call latency, time budget, confidence and tokens. It has seeded courses, offline tests, and a benchmark that makes no API calls unless you pass `--live`. No live benchmark has been run yet.
